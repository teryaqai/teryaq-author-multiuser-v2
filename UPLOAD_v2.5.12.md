# TERYAQ Master Tool v2.5.12 — deployment and review

## Deploy

1. Replace the repository files with this release folder and deploy to Render.
2. Open the app online on every installed device once. Verify the Dashboard shows v2.5.12 before working offline.
3. No SQL migration or Edge Function change is needed.

## Review

1. Choose **Shooting Script**. The Script information step asks for Script writer, optional start/end dates, Course, Chapter and Script notes. Confirm the same card appears in the editor.
2. Type two spoken lines; select a word in the second line, switch to Script Cues and apply **تشديد**. Confirm only that word changes. Try another selection and repeat. Test left, center and right alignment and confirm each persists after Save/reopen.
3. Select a word and press **×2**. The marker should appear immediately beside the word in the same line, also in Teleprompter and PDF/HTML export.
4. In Teleprompter, set a middle reading region and press Play. The text should move through a stationary reading band. Adjust top/bottom/custom reading regions and dark/light themes. Outside the band should be visibly darker in dark mode.
5. Enter fullscreen and press Space twice: Play, then Pause. Space inside editable spoken text should still type a space. Edit spoken text and confirm the script is updated after returning to Text Formatting and reopening.
6. Open an existing v2.5.11 script with an old standalone ×2 cue. Confirm it now appears inline without losing the spoken text. Check existing Scientific Draft Text/Figures editors.
