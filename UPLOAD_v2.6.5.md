# TERYAQ Master Tool v2.6.5 — release instructions

1. Upload the complete v2.6.5 package to the existing Render site. Keep `index.html`, all four `v2.6.5` JavaScript/CSS files, `sw.js`, `VERSION.json`, icons, fonts, and vendor assets together. This update needs no new database migration. If migration 015 from v2.6.3 has not yet been applied, apply it for the administrator cloud version tools.
2. Open a Scientific Draft – Figures. The standalone “Export figures only (PDF)” button below Draft information should be gone. Open File → Export and check that “Figures only (PDF)” is present alongside the other options.
3. Use “Figures only (PDF)” to confirm it still asks for the correct editorial version and opens the image-and-Figure-code print/PDF view. Reload an installed app if it still shows the previous cached release.

The installed app should display v2.6.5. See `UPLOAD_v2.6.4.md` for the previous figures File ribbon update.
