الاسم والدومين المعتمدان

TERYAQ Work — مساحة عمل ترياق هو اسم العرض الجديد. الدومين الذي اشتريته هو teryaqwork.io من Hostinger؛ يُستخدم مباشرة دون work. إضافية.

الموقع يبقى على Render وقاعدة البيانات وتسجيل الدخول على Supabase. لا تحتاج شراء استضافة Hostinger لهذا الربط.

  1. في Render افتح خدمة الأداة الحالية → Settings → Custom Domains ثم أضف teryaqwork.io.
  2. انسخ سجلات DNS التي يعرضها Render إلى إعدادات DNS للدومين في Hostinger، ثم ارجع إلى Render للتحقق من الدومين وشهادة HTTPS. استخدم القيم المعروضة لخدمتك، ولا تخمّن عنوان IP.
  3. في Supabase → Authentication → URL Configuration حدّث Site URL إلى https://teryaqwork.io وأضف Redirect URLs اللازمة للدخول واستعادة كلمة السر. اختبر الدخول والاستعادة قبل توزيع الرابط.
  4. الدومين الجديد أصل مختلف للمتصفح: المستندات المحلية غير المتزامنة لا تنتقل إليه تلقائيًا. زامن أو صدّر نسخة احتياطية أولًا، ثم سجّل الدخول على الدومين الجديد، وأعد تثبيت PWA منه عند الحاجة.
منع الفهرسة: أضيف noindex إلى الصفحة وإلى ترويسة Render في render.yaml. تأكد من تطبيق X-Robots-Tag بإعدادات Headers إذا كانت خدمتك لا تحدّث إعدادات Blueprint تلقائيًا. noindex لا يمنع فتح الرابط ولا يلغي صلاحيات الحسابات، وإزالة نتيجة سابقة من محرك البحث قد تستغرق وقتًا.

هذا التحديث يجهز الاسم والكود والتعليمات؛ لم تُعدّل سجلات DNS أو روابط Supabase خارجيًا.

DEV-001 — بوابة تحقق قبل ظهور واجهة الأداة

الحالة: مقترح قيد الدراسة — لم يُنفّذ. تاريخ الإضافة وآخر تحديث: 18 أكتوبر 2026.

إضافة طبقة وصول قبل واجهة teryaqwork.io بقائمة محددة من إيميلات أعضاء الفريق.

  1. يفتح العضو الرابط ويدخل إيميله المسموح.
  2. يصل كود تحقق إلى الإيميل؛ بعد إدخاله يصل لواجهة الأداة.
  3. يسجّل الدخول داخل TERYAQ Work بحسابه الحالي كالمعتاد.
  4. مدة جلسة البوابة المقترحة أسبوع / 7 أيام لتقليل تكرار التحقق، مع مراجعة سياسات الجلسة وقت الإعداد.

Render وSupabase يبقيان كما هما. البوابة إضافة للخصوصية ولا تستبدل حماية البيانات بالحسابات والصلاحيات.

قبل تفعيلها يجب تعطيل رابط Render الافتراضي بعد نجاح الدومين الخاص، والتحقق من عدم وجود دومين أو مسار بديل يتجاوز البوابة، وفحص الدخول واستعادة كلمة السر والمزامنة وPWA. لم تُفعّل Cloudflare Access أو يُنقل DNS في هذا التحديث.

ملاحظات القرار: تم اختيار الدومين وشراؤه: teryaqwork.io، والاسم المعتمد TERYAQ Work. مدة الأسبوع ما زالت مقترحة وتراجع عند الإعداد؛ تنتهي الجلسة أو يحتاج جهاز أو متصفح جديد تحققًا جديدًا.

المتطلبات المتبقية: تجهيز حساب Cloudflare، تحديد إيميلات الفريق المسموحة، والوصول لإعدادات Render وSupabase. الخطوة التالية: اعتماد تفاصيل البوابة بعد اختبار الدومين؛ تسجيل الاقتراح لا يعني تنفيذه.

مراجع الإعداد: Render Custom Domains · Cloudflare One-time PIN · Cloudflare Sessions.
