# TERYAQ Master Tool v2.6.6 — release instructions

1. Upload the complete v2.6.6 package to the existing Render site. Deploy `index.html`, the four `v2.6.6` JavaScript/CSS files, `sw.js`, `VERSION.json`, icons, fonts, and vendor assets together. This release includes the v2.6.5 duplicate export-button removal. No new database migration is needed.
2. Open a Shooting Script with regular text, a heading, an Intro, a Light break, and bullet levels 1–3 (both LTR and RTL). All drag boxes should occupy the same left gutter, and the supplied dot icon should sit centrally within each box. Drag an item and use the arrow keys while focused on its handle to confirm reordering still works.
3. In a Figures draft, confirm that Figures only (PDF) appears under File → Export and the duplicate standalone button is gone.
4. If an installed app still shows the old layout, reload it once after deployment and confirm the displayed version is v2.6.6.

If migration 015 from v2.6.3 has not yet been applied, apply it separately for administrator cloud version tools.
