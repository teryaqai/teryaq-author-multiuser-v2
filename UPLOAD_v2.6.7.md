# TERYAQ Master Tool v2.6.7 — release instructions

1. Upload the entire v2.6.7 package to the existing Render site. Deploy `index.html`, all four `v2.6.7` JavaScript/CSS files, `sw.js`, `VERSION.json`, icons, fonts, and vendor assets together. No new database migration is needed.
2. Open a Shooting Script and a Scientific Draft – Text. Each content block, including headings, cues, lists, tables, and figure placeholders, should have a 20 × 20 px drag box above a 20 × 20 px checkbox on the same left edge. The checkbox is one white outlined box, green with a white check when selected.
3. Select two or more blocks. “Delete selected” appears above the page; approve the confirmation and check that only those blocks disappear. Press Undo once to restore both. If every block is deleted, one empty paragraph should remain for editing.
4. Drag a heading or list item in both templates and check that the Outline, numbering, and table register reflect the new order. Print/export and View Only should not show selection boxes. Reload an installed app once if it still shows a cached older layout.

The installed app should display v2.6.7. This package includes the figure export cleanup from v2.6.5 and script drag alignment from v2.6.6.
