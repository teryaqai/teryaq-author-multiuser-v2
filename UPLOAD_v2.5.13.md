# TERYAQ Master Tool v2.5.13 — deployment and review

## Deploy

1. Replace the repository files with this release folder and deploy to Render.
2. Open the app online on every installed device once. Verify the Dashboard shows v2.5.13 before working offline.
3. No SQL migration or Edge Function change is needed.

## Review

1. Create or open a Shooting Script. The Script information form has no separate Script title input; the chapter and course still contribute to the document name.
2. Type Arabic and English lines. Click each right to left / left to right button, then left / center / right alignment on a selected line. Confirm each moves or aligns the text, highlights its active control and survives Save/reopen. Repeat on a bullet or numbered line.
3. Insert ×2 beside a word, press Space, type a few more words. Confirm the new text is ordinary black Body text in both Script and Teleprompter.
4. In Teleprompter, press Play at 0.2×, 1× and 3× on a long script. All speeds should move; 3× should be visibly faster. Pause, switch to fullscreen and use Space to Play/Pause.
5. Verify Scientific Draft Text and Figures continue to open, save and render.
