Help center

Guide / دليل الاستخدام

Search the full bilingual guide whenever you need help.

Getting started · البدء

Use New document, choose a template, press Next, complete Draft or Script Information, then create the document.

اضغط New document، اختر القالب، ثم التالي، وأدخل معلومات المستند قبل فتح المحرر.

Offline work · العمل دون إنترنت

Open the installed PWA once while online. Later open the installed app and choose Continue Offline. Every edit is saved in IndexedDB and queued for sync.

افتح التطبيق المثبت مرة واحدة وأنت متصل. لاحقًا افتحه واختر Continue Offline؛ تُحفظ التعديلات محليًا وتنتظر عودة الإنترنت.

Sync · المزامنة

Auto Sync sends queued work whenever the device is online. Sync Now runs it immediately. “Waiting sync” is safe local work that has not reached Supabase yet.

المزامنة التلقائية ترسل التعديلات عند توفر الإنترنت. زر Sync Now يبدأها فورًا. حالة Waiting sync تعني أن العمل محفوظ محليًا ولم يصل للسحابة بعد.

Conflicts · التعارضات

A conflict is shown on its affected document. Choose Keep local, Use server, or Save both. Nothing is overwritten automatically.

يظهر التعارض على المستند المتأثر. اختر النسخة المحلية أو السحابية أو الاحتفاظ بالنسختين، ولا يتم الاستبدال تلقائيًا.

History and Versions · السجل والنسخ

History contains local recovery snapshots. A cloud Version is an immutable state created after an accepted sync. Open a document and use History / Versions.

History يحتوي نقاط استعادة محلية. أما Version فهي نسخة سحابية ثابتة تُنشأ بعد المزامنة الناجحة. ستجدها داخل المستند عبر History / Versions.

Trash · سلة المحذوفات

Deleting moves the document to Trash. Restore returns it to Documents and queues the recovery for cloud sync.

حذف المستند ينقله إلى السلة، والاستعادة تعيده إلى Documents وتضعه في قائمة المزامنة.

Account and password · الحساب وكلمة المرور

Account lets you change the username shown in the greeting. Password changes require an internet connection and apply to every device.

من صفحة Account تستطيع تعديل اسم المستخدم الظاهر في الترحيب. تغيير كلمة المرور يحتاج إنترنت وينطبق على كل الأجهزة.

Admin · الأدمن

Admins can review synced users, documents, cloud versions, and deleted documents. Local-only work stays private until it syncs.

يستطيع الأدمن مراجعة المستخدمين والمستندات المتزامنة والنسخ والمحذوفات. العمل المحلي فقط لا يظهر حتى تتم مزامنته.

Troubleshooting · حل المشاكل

If offline launch fails, reconnect once, refresh the installed app, then test again. If sync fails, verify Settings & Sync and press Sync Now.

إذا لم يفتح التطبيق دون إنترنت، اتصل مرة واحدة وحدّث التطبيق المثبت ثم جرّب مجددًا. عند فشل المزامنة راجع Settings & Sync واضغط Sync Now.

Document Outline

Summary of figure outcomes

Each figure follows one of the five outcomes below.

Order 1 — KEEPKeep the figure as it is when copyright is clear and it already fits Teryaq style.
Order 2 — CHANGEMake specific minor changes when copyright is not an issue.
Order 3 — RECREATERecreate with AI using defined scientific-fidelity rules.
Order 4 — DESIGNCreate a new Teryaq-designed figure, especially charts and simple illustrations.
Order 5 — SEARCHSearch for a suitable figure when an appropriate one cannot be found by the draft writer.
Instructions & Notes

Order 1: only when the writer is certain there are no copyright issues and the style is suitable.

Order 3 defaults: Tajawal/English; change skin color and gender when suitable; minor color change; preserve anatomy/histology exactly; alter only non-scientific visual features; remove logos/signatures/watermarks/unnecessary titles; white background; final image 1:1. Any exception or extra change must be stated in PROMPT → DETAILS.

Order 4: clearly define the desired final output. Order 5: clearly describe what should be searched for.

Very important: figure code contains only the figure number; title is mandatory; caption is optional.

Steps of Creation
  1. Choose a clear, high-quality figure matching Teryaq usage.
  2. Add it to the Figure area.
  3. Write the figure code.
  4. Write a short title; use Caption for extra clarification.
  5. Always record the source.
  6. Choose the correct Order.
  7. Write details in PROMPT → DETAILS.
  8. Choose copyright status; use “I don't know” when uncertain.
  9. Add any extra notes.
