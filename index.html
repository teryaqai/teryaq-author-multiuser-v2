سير العمل في ترياق

ابدأ من هنا وارجع للدليل عند أي مشكلة

يوضح الدليل مكان كل خيار، ومعنى كل حالة، والخطوات المناسبة عند حدوث مشكلة.

01Getting startedتسجيل الدخول والتثبيت والبدء

First use on a device

  1. Open the HTTPS Render link while connected to the internet.
  2. On the login page, expand First-time cloud setup.
  3. Enter the Supabase Project URL and publishable key, then save.
  4. Sign in with the account created for you by the administrator.
  5. Press Sync Now and wait until the status becomes Synced ✓.
  6. Install the PWA from Chrome/Edge or Add to Home Screen on iPad.

أول استخدام على الجهاز

  1. افتح رابط Render الآمن HTTPS وأنت متصل بالإنترنت.
  2. في صفحة الدخول افتح First-time cloud setup.
  3. أدخل Project URL وPublishable Key ثم احفظ الاتصال.
  4. سجّل الدخول بالحساب الذي أنشأه أو وافق عليه الأدمن.
  5. اضغط Sync Now وانتظر حتى تظهر Synced ✓.
  6. ثبّت التطبيق من Chrome/Edge أو Add to Home Screen على الأيباد.
Important: The cloud connection is saved separately on each browser/device. Never enter a service-role key.
02Documents and templatesإنشاء المستندات والعمل داخلها

Create a document

  1. Choose New document.
  2. Select the required template box.
  3. Press Next.
  4. Complete Draft Information or the information requested by that template.
  5. Choose Create & continue to open the editor.

Where are document actions?

Go to Documents. Open and History & Versions are visible. Duplicate, Export, and Move to Trash are inside the ••• menu.

إنشاء مستند

  1. اختر New document.
  2. اختر بوكس القالب المطلوب.
  3. اضغط Next.
  4. أكمل Draft Information أو المعلومات الخاصة بالقالب.
  5. اضغط Create & continue لفتح المحرر.

أين أجد خيارات المستند؟

من صفحة Documents. زر Open وHistory & Versions ظاهران، بينما Duplicate وExport وMove to Trash داخل قائمة •••.

Autosave: Editor changes are saved locally automatically. Save confirms the local save; cloud delivery is shown separately by the sync status.
03Editor and Arabic listsالمحرر والقوائم العربية

Editor controls

  • Styles: body and heading levels.
  • Text Formatting: bold, italic, and font size.
  • Bullets & Numbering: structured list levels.
  • Figures/Tables: placeholders and structured tables.
  • Validate: checks missing or inconsistent structure.
  • Export: creates a portable .teryaq file.
  • Print / PDF: generates formatted output.

اتجاه البوليت والنامبرنج

يعتمد الاتجاه على أول حرف فعلي في كل بند: إذا بدأ النص بالعربية تظهر العلامة من اليمين، وإذا بدأ بالإنجليزية تبقى من اليسار. يمكن أن يحتوي نفس المستند على بنود عربية وإنجليزية باتجاهين مختلفين.

الرجوع

استخدم زر Back أعلى المحرر للعودة؛ يتم حفظ التعديلات المحلية المعلقة قبل الخروج.

04Offline workالعمل على اللابتوب والأيباد دون إنترنت

Laptop

  1. Install the app from Chrome or Edge while online.
  2. Open the installed app once and complete a successful sign-in and sync.
  3. When offline, launch the installed app—not a new private/incognito window.
  4. If the login page appears, choose Continue Offline.
  5. Work normally; changes show as Offline / saved locally.

iPad

  1. Open the site in Safari while online.
  2. Share → Add to Home Screen.
  3. Open the new Home Screen icon once online.
  4. Later launch the icon offline and choose Continue Offline if requested.

ماذا يحدث أثناء الأوفلاين؟

يُحفظ كل تعديل داخل IndexedDB على نفس الجهاز، وتدخل التغييرات في قائمة انتظار. لا يحتاج إنشاء المستند أو تعديله أو تصديره إلى الإنترنت بعد تجهيز الجهاز أول مرة. عند عودة الاتصال يبدأ Auto Sync تلقائيًا.

تنبيه

بيانات الأوفلاين مرتبطة بالجهاز والمتصفح والحساب. مسح بيانات الموقع أو حذف التطبيق قد يمسح العمل المحلي غير المتزامن، لذلك استخدم النسخ الاحتياطي قبل ذلك.

05Sync status and Auto Syncحالات المزامنة ومعناها

synced Saved locally and accepted by the cloud.

pending Safe on this device and waiting to upload.

local-only Exists only on this device so far.

conflict Another cloud change needs your decision.

Auto Sync

يعمل افتراضيًا عند توفر الإنترنت: بعد الحفظ، وعند عودة الاتصال، وعند فتح التطبيق، مع فحص دوري. يمكنك تشغيله أو إيقافه من Settings & Sync.

متى أضغط Sync Now؟

بعد أول تسجيل دخول على جهاز جديد، وقبل تغيير الجهاز، وبعد حل تعارض، أو إذا بقيت حالة pending مدة غير طبيعية.

Privacy: Admins see only work that has reached Supabase. Local-only edits remain on the user's device.
06Conflictsكيف أعرف التعارض وأحله؟

Where it appears

The affected document shows a red conflict status in Documents. The top conflict button lists all unresolved conflicts.

Resolution choices

  • Keep local: upload this device's copy as the next cloud version.
  • Use server: discard the conflicting local copy and accept the cloud copy.
  • Save both: keep the cloud copy on the original and preserve local work as a new document.

متى يحدث؟

عندما يعدّل جهازان المستند نفسه انطلاقًا من نفس النسخة قبل أن يتزامنا. لا يستبدل التطبيق أي نسخة تلقائيًا.

الخيار الأكثر أمانًا عند الشك

اختر Save both ثم راجع النسختين يدويًا، خصوصًا للمحتوى العلمي.

07History and cloud Versionsما الفرق وأين أجدها؟

History

Local recovery snapshots kept on this device. Open the document and choose History / Versions. You can create a snapshot or restore an earlier state.

Version

An immutable cloud snapshot created after every accepted synchronization. Admin → Versions can download individual versions, and an admin can download all versions for one document.

الفرق العملي

History للاستعادة السريعة على الجهاز نفسه، أما Version فهي سجل سحابي ثابت للمزامنات الناجحة. استعادة History لا تمسح التاريخ؛ تحفظ الحالة الحالية أولًا ثم تعيد النسخة المختارة.

Remember: Undo/Redo is for the current editing session; History is local recovery; Version is the immutable cloud archive.
08Trash and restoreالحذف والاستعادة

Move to Trash

Documents → ••• → Move to Trash. A complete recoverable copy is kept locally and the soft-delete is queued for cloud sync.

Restore

Trash → Restore. The document returns to Documents and the recovery is queued for synchronization. Download saves a portable copy without restoring.

صلاحيات السلة

المستخدم يرى محذوفاته فقط. الأدمن يرى المحذوفات المتزامنة لجميع الحسابات من Admin → All Trash. الحذف النهائي غير متاح في v2.3 إلى أن تُعتمد مدة الاحتفاظ وقواعد الصلاحيات وسجل التدقيق.

09Account, username, and passwordالحساب واسم المستخدم وكلمة المرور

Username

Account → Username → Save. It replaces the email in the greeting and sidebar. It does not change the sign-in email.

Password

Account → enter and confirm a password of at least eight characters. Internet is required, and the change applies to every device.

الخروج

Sign out يزيل الجلسة ويبقي مساحة العمل المحلية. أما Sign out & Remove Local Data فيحذف بيانات هذا الحساب من الجهاز فقط؛ لذلك تأكد من المزامنة أو النسخ الاحتياطي أولًا.

10Admin workspaceدليل الأدمن

Current pages

  • Overview: synchronized users, documents, revisions, and deleted counts.
  • Users: usernames, emails, roles, and active document counts.
  • Documents: all synchronized active documents with download and versions.
  • Versions: latest cloud versions and downloads.
  • All Trash: synchronized deleted documents from every account.

حدود رؤية الأدمن

لا يستطيع الأدمن رؤية تعديل ما زال محليًا على جهاز مستخدم. يجب أن تتم المزامنة أولًا. كما أن الأدمن في v2.3 يراجع وينزّل ولا يعدّل مستندات المستخدمين مباشرة.

11Backups and moving devicesالنسخ الاحتياطي وتغيير الجهاز

Before changing a device

  1. Press Sync Now and confirm Synced ✓.
  2. Settings & Sync → Export Workspace Backup.
  3. Keep important .teryaq exports separately.
  4. On the new device, configure Supabase, sign in, then Sync Now.

ما الذي يحتويه Workspace Backup؟

المستندات المحلية، القوالب، نقاط History، السلة، والتعارضات الخاصة بالحساب على هذا الجهاز. الاستعادة تُنشئ نسخة أمان محلية قبل الكتابة.

12Troubleshootingالمشكلة والحل خطوة بخطوة

App does not open offline

  1. Reconnect once.
  2. Open the installed app and refresh.
  3. Wait for the page to finish loading.
  4. Close it, disconnect, and test again from the installed icon.

Sync error

  1. Confirm the internet connection.
  2. Open Settings & Sync and verify Project URL/key.
  3. Press Sync Now.
  4. If Conflict appears, resolve it from the affected document.

Document missing on another device

  1. On the original device, confirm it is not pending/local-only.
  2. Press Sync Now.
  3. On the second device, sign into the same email and press Sync Now.

اختفى العمل بعد تسجيل الدخول

  1. تأكد أنك داخل الحساب نفسه.
  2. إذا كان العمل على جهاز آخر ولم يتزامن، افتح الجهاز الأصلي.
  3. اختر Continue Offline عند الحاجة ثم اضغط Sync Now بعد عودة الإنترنت.

لا يظهر زر Admin

  1. تحقق أن role للحساب هو admin في Supabase.
  2. سجّل الخروج ثم الدخول لتحديث الصلاحية.
  3. يحتاج Admin إلى اتصال إنترنت.

النص العربي أو البوليت في الاتجاه الخطأ

تأكد أن أول حرف فعلي في البند عربي. الاتجاه يُحسب لكل بند على حدة؛ البنود التي تبدأ بالإنجليزية تبقى من اليسار.

Document Outline

Summary of figure outcomes

Each figure follows one of the five outcomes below.

Order 1 — KEEPKeep the figure as it is when copyright is clear and it already fits Teryaq style.
Order 2 — CHANGEMake specific minor changes when copyright is not an issue.
Order 3 — RECREATERecreate with AI using defined scientific-fidelity rules.
Order 4 — DESIGNCreate a new Teryaq-designed figure, especially charts and simple illustrations.
Order 5 — SEARCHSearch for a suitable figure when an appropriate one cannot be found by the draft writer.
Instructions & Notes

Order 1: only when the writer is certain there are no copyright issues and the style is suitable.

Order 3 defaults: Tajawal/English; change skin color and gender when suitable; minor color change; preserve anatomy/histology exactly; alter only non-scientific visual features; remove logos/signatures/watermarks/unnecessary titles; white background; final image 1:1. Any exception or extra change must be stated in PROMPT → DETAILS.

Order 4: clearly define the desired final output. Order 5: clearly describe what should be searched for.

Very important: figure code contains only the figure number; title is mandatory; caption is optional.

Steps of Creation
  1. Choose a clear, high-quality figure matching Teryaq usage.
  2. Add it to the Figure area.
  3. Write the figure code.
  4. Write a short title; use Caption for extra clarification.
  5. Always record the source.
  6. Choose the correct Order.
  7. Write details in PROMPT → DETAILS.
  8. Choose copyright status; use “I don't know” when uncertain.
  9. Add any extra notes.
