01Getting startedتسجيل الدخول والتثبيت والبدء

First use on a device

  1. Open the HTTPS Render link while connected to the internet.
  2. On the login page, press Cloud setup. It opens beside Sign in on desktop or as a scrollable bottom sheet on mobile.
  3. Enter the Supabase Project URL and publishable key, then save.
  4. Sign in with the account created for you by the administrator.
  5. Press Sync Now and wait until the status becomes Synced ✓.
  6. Install the PWA from Chrome/Edge or Add to Home Screen on iPad.

أول استخدام على الجهاز

  1. افتح رابط Render الآمن HTTPS وأنت متصل بالإنترنت.
  2. في صفحة الدخول اضغط Cloud setup؛ تظهر بجانب تسجيل الدخول على اللابتوب أو كنافذة سفلية قابلة للتمرير على الجوال.
  3. أدخل Project URL وPublishable Key ثم احفظ الاتصال.
  4. سجّل الدخول بالحساب الذي أنشأه أو وافق عليه الأدمن.
  5. اضغط Sync Now وانتظر حتى تظهر Synced ✓.
  6. ثبّت التطبيق من Chrome/Edge أو Add to Home Screen على الأيباد.
Important: The cloud connection is saved separately on each browser/device. Never enter a service-role key.
02Documents and templatesإنشاء المستندات والعمل داخلها

Create a document

  1. Choose New document.
  2. Select the required template box.
  3. Press Next.
  4. Complete Draft Information or the information requested by that template.
  5. Choose Create & continue to open the editor.

Where are document actions?

Go to Documents. Open and History & Versions are visible. Duplicate, Export, and Move to Trash are inside the ••• menu. Use the square checkboxes to select several visible documents or select all, then move the selected group to Trash.

إنشاء مستند

  1. اختر New document.
  2. اختر بوكس القالب المطلوب.
  3. اضغط Next.
  4. أكمل Draft Information أو المعلومات الخاصة بالقالب.
  5. اضغط Create & continue لفتح المحرر.

أين أجد خيارات المستند؟

من صفحة Documents. زر Open وHistory & Versions ظاهران، بينما Duplicate وExport وMove to Trash داخل قائمة •••. استخدم مربعات التحديد لاختيار عدة ملفات ظاهرة أو تحديد الكل، ثم انقل المجموعة المختارة إلى السلة.

Autosave: Editor changes are saved locally automatically. Save confirms the local save; cloud delivery is shown separately by the sync status.
03Editor and Arabic listsالمحرر والقوائم العربية

Editor layout

  • Top action bar: Save, Sync, Validate, History / Versions, and one Export menu for Draft, PDF, Template, or standalone HTML.
  • Ribbon tabs: Home contains styles and lists, Insert contains figures and new/imported tables, Table appears for a selected table cell, and View contains View only, zoom, and Outline.
  • Import DOCX Table: choose a DOCX, select detected tables, review warnings, complete code/title/caption, then insert native editable tables. The file stays on your device.
  • Sidebar: use its arrow to switch between icons-only and icons with labels.
  • Outline: choose View → Outline to navigate H1/H2 sections. The drawer overlays the workspace and never changes the A4 page width.
  • Draft information: remains separate from the A4 writing page.
  • Table information: every named table gets a linked row for code, title, and optional caption. Editing the row updates that table's caption.
  • After a table: choose + Continue writing. New and imported tables also receive a normal paragraph immediately after them.

Formatting behavior

Moving the controls does not change any style definition. Inline marks such as Side Note, Note to Delete, High-Yield, and Clinical Correlation still require selected text.

ترتيب المحرر

  • الشريط الأول: الحفظ والمزامنة والتحقق والنسخ السابقة، وقائمة Export واحدة لمسودة TERYAQ أو PDF أو قالب أو HTML مستقل.
  • تبويبات الشريط: Home للستايلات والتنسيقات والقوائم، Insert للفيجر والجداول الجديدة أو المستوردة، Table لأدوات الجدول المحدد، وView للعرض فقط والزوم والـOutline.
  • Import DOCX Table: اختر ملف DOCX، حدّد الجداول، راجع التنبيهات، أدخل الكود والعنوان والـCaption ثم أدرجها كجداول TERYAQ قابلة للتعديل. الملف لا يغادر جهازك.
  • القائمة الجانبية: استخدم السهم للتبديل بين الأيقونات فقط أو الأيقونات مع الأسماء.
  • Document Outline: افتحه من View → Outline للتنقل بين H1 وH2؛ يفتح فوق مساحة العمل ولا يغيّر عرض صفحة A4.
  • Table information: يظهر لكل جدول مُسمّى صف مرتبط للكود والعنوان والـCaption الاختياري، وأي تعديل عليه ينعكس على الجدول.
  • الكتابة بعد الجدول: اضغط + Continue writing أسفل الجدول؛ كما تُنشأ فقرة Body تلقائيًا بعد أي جدول جديد أو مستورد.

اتجاه البوليت والنامبرنج

يعتمد الاتجاه على أول حرف فعلي في كل بند: إذا بدأ النص بالعربية تظهر العلامة من اليمين، وإذا بدأ بالإنجليزية تبقى من اليسار. يمكن أن يحتوي نفس المستند على بنود عربية وإنجليزية باتجاهين مختلفين.

الرجوع

استخدم زر Back أعلى المحرر للعودة؛ يتم حفظ التعديلات المحلية المعلقة قبل الخروج.

04Offline workالعمل على اللابتوب والأيباد دون إنترنت

Laptop

  1. Install the app from Chrome or Edge while online.
  2. Open the installed app once and complete a successful sign-in and sync.
  3. When offline, launch the installed app—not a new private/incognito window.
  4. If the login page appears, choose Continue Offline.
  5. Work normally; changes show as Offline / saved locally.

iPad

  1. Open the site in Safari while online.
  2. Share → Add to Home Screen.
  3. Open the new Home Screen icon once online.
  4. Later launch the icon offline and choose Continue Offline if requested.

ماذا يحدث أثناء الأوفلاين؟

يُحفظ كل تعديل داخل IndexedDB على نفس الجهاز، وتدخل التغييرات في قائمة انتظار. لا يحتاج إنشاء المستند أو تعديله أو تصديره إلى الإنترنت بعد تجهيز الجهاز أول مرة. عند عودة الاتصال يبدأ Auto Sync تلقائيًا.

تنبيه

بيانات الأوفلاين مرتبطة بالجهاز والمتصفح والحساب. مسح بيانات الموقع أو حذف التطبيق قد يمسح العمل المحلي غير المتزامن، لذلك استخدم النسخ الاحتياطي قبل ذلك.

05Sync status and Automatic Syncحالات المزامنة ومعناها

synced Saved locally and accepted by the cloud.

pending Safe on this device and waiting to upload.

local-only Exists only on this device so far.

conflict Another cloud change needs your decision.

المزامنة التلقائية

تعمل دائمًا عند توفر الإنترنت: بعد الحفظ، وعند عودة الاتصال، وعند فتح التطبيق أو الرجوع إليه، ومع فحص كل 15 ثانية. إذا فشلت محاولة مؤقتًا يبقى التعديل محفوظًا محليًا ويُعاد إرساله تلقائيًا.

متى أضغط Sync Now؟

بعد أول تسجيل دخول على جهاز جديد، وقبل تغيير الجهاز، وبعد حل تعارض، أو إذا بقيت حالة pending مدة غير طبيعية. تعرض Settings آخر محاولة وأي خطأ.

Privacy: Admins see only work that has reached Supabase. Local-only edits remain on the user's device.
06Conflictsكيف أعرف التعارض وأحله؟

Where it appears

The affected document shows a red conflict status in Documents. The top conflict button lists all unresolved conflicts.

Resolution choices

  • Keep local: upload this device's copy as the next cloud version.
  • Use server: discard the conflicting local copy and accept the cloud copy.
  • Save both: keep the cloud copy on the original and preserve local work as a new document.

متى يحدث؟

عندما يعدّل جهازان المستند نفسه انطلاقًا من نفس النسخة قبل أن يتزامنا. لا يستبدل التطبيق أي نسخة تلقائيًا.

الخيار الأكثر أمانًا عند الشك

اختر Save both ثم راجع النسختين يدويًا، خصوصًا للمحتوى العلمي.

07History and cloud Versionsما الفرق وأين أجدها؟

History

Local recovery snapshots kept on this device. Open the document and choose History / Versions. You can create a snapshot or restore an earlier state.

Cloud Version

An immutable cloud snapshot created after every accepted synchronization. Choose Cloud versions & compare to select an earlier and later version, review metadata/content changes side by side, download one version, or download the complete archive. Comparison is read-only and never changes the live document.

الفرق العملي

History للاستعادة السريعة على الجهاز نفسه، أما Version فهي نسخة سحابية ثابتة لكل مزامنة ناجحة. من Cloud versions & compare اختر نسختين لرؤية المضاف والمحذوف والمتغير والمنقول دون تعديل الملف الحالي. استعادة History تحفظ الحالة الحالية أولًا ثم تعيد النسخة المختارة.

Remember: Undo/Redo is for the current editing session; History is local recovery; Version is the immutable cloud archive.
08Trash and restoreالحذف والاستعادة

Move to Trash

Documents → ••• → Move to Trash. A complete recoverable copy is kept locally and the soft-delete is queued for cloud sync. A deleted document no longer contributes to the active conflict count.

Restore

Trash → Restore returns your document. Admin → All Trash can also restore a user's synchronized deleted document; it returns as a higher cloud version and reaches the owner on the next sync.

Permanent deletion

Only an administrator may permanently delete a synchronized Trash item, only after the configured 30-day retention period, and only after typing PURGE. The action removes version history and Storage attachments and remains recorded in the Audit Log.

الحذف والتعارض

عند نقل ملف متعارض إلى السلة يختفي من عداد التعارضات النشطة، لكن التطبيق يحفظ حالته. إذا استُعيد الملف من سلة المستخدم يعود معه التعارض ليُحل بالطريقة الصحيحة.

صلاحيات السلة

المستخدم يرى محذوفاته فقط. الأدمن يرى المحذوفات المتزامنة لكل الحسابات من Admin → All Trash ويمكنه استعادتها. الحذف النهائي محصور بالأدمن، ولا يسمح به السيرفر قبل مرور 30 يومًا، ولا يمكن التراجع عنه.

09Profile, account, and passwordالبروفايل والحساب وكلمة المرور

Request access

On sign-in choose Request an Account, send your name and email, then wait for admin approval. The request alone does not create immediate access.

Profile

Open the avatar menu in the top-right corner → Profile. Change the display name or choose a JPG/PNG/WebP photo. Reposition and zoom the photo in the crop tool, then apply it. The result is saved locally first and uploaded when internet returns. Use default restores the vector avatar.

Password and Settings

Use Profile to change an 8+ character password. Use the avatar menu → Settings for Sync, Cloud connection, backups, device data, and Sign out & Remove Local Data.

البروفايل

اضغط الصورة أعلى يمين الداشبورد ثم Profile. بعد اختيار الصورة يمكنك تحريكها وتكبيرها وضبط القص قبل اعتمادها؛ تُحفظ محليًا أولًا ثم تُرفع عند عودة الإنترنت. زر Use default يعيد الصورة الافتراضية.

الإعدادات والخروج

من قائمة الصورة اختر Settings للمزامنة والنسخ الاحتياطي وبيانات الجهاز. Sign out يبقي البيانات المحلية، أما Sign out & Remove Local Data فيحذف بيانات الحساب من هذا الجهاز فقط.

10Admin workspaceدليل الأدمن

Admin pages

  • Overview: synchronized totals and the limits of admin visibility.
  • Analytics: 7/30/90/365-day cloud activity, versions, users, documents, conflicts, and requests.
  • Content Options: authors, courses, and course-specific chapters.
  • Users / Documents / Versions: synchronized accounts and documents, downloads, archives, and read-only version comparison.
  • Cloud Conflicts: status, owner, device, and version metadata only; the owner still chooses the content resolution.
  • Account Requests: approve and invite, reject, or resend an invitation.
  • Audit Log: security/administration events with CSV export.
  • All Trash: restore any synchronized deleted document, or permanently purge an eligible item after retention.

صفحات الأدمن

Analytics للإحصائيات السحابية، وCloud Conflicts لبيانات التعارض دون عرض المسودة المحلية، وAccount Requests للموافقة وإرسال الدعوة، وAudit Log لمراجعة الأحداث وتصدير CSV، وAll Trash للاستعادة أو الحذف النهائي بعد مدة الاحتفاظ.

حدود رؤية الأدمن

لا يستطيع الأدمن رؤية تعديل ما زال محليًا على جهاز مستخدم؛ يجب أن تتم المزامنة أولًا. حل محتوى التعارض يبقى عند مالك المستند.

11Backups and moving devicesالنسخ الاحتياطي وتغيير الجهاز

Before changing a device

  1. Press Sync Now and confirm Synced ✓.
  2. Settings & Sync → Export Workspace Backup.
  3. Keep important .teryaq exports separately.
  4. On the new device, configure Supabase, sign in, then Sync Now.

ما الذي يحتويه Workspace Backup؟

المستندات المحلية، القوالب، نقاط History، السلة، والتعارضات الخاصة بالحساب على هذا الجهاز. الاستعادة تُنشئ نسخة أمان محلية قبل الكتابة.

12Troubleshootingالمشكلة والحل خطوة بخطوة

App does not open offline

  1. Reconnect once.
  2. Open the installed app and refresh.
  3. Confirm the Dashboard shows the expected version number.
  4. Close every TERYAQ window, reopen the installed app online once, then test offline.

Sync or ownership error

  1. Do not clear browser data; the local draft is preserved first.
  2. Press Sync again. A document-ID ownership mismatch is repaired automatically as a new safe cloud identity.
  3. If Conflict appears, open the affected document from Documents and review both copies.

Document missing on another device

  1. On the original device, confirm it is not pending/local-only.
  2. Press Sync and wait for a cloud version number.
  3. On the second device, confirm the same app version, sign into the same email, and press Sync Now.

اختفى العمل بعد تسجيل الدخول أو الرجوع

  1. لا تمسح بيانات الموقع أو التطبيق.
  2. تحقق من رقم الإصدار الظاهر في Dashboard؛ يجب أن يكون نفسه على كل الأجهزة.
  3. إذا ظهر Conflict فهذا يعني أن جهازًا آخر أرسل نسخة أحدث؛ تبقى المسودة المحلية محفوظة ولا تُستبدل تلقائيًا.
  4. إذا كان العمل على جهاز آخر بحالة pending، افتح الجهاز الأصلي واضغط Sync وانتظر رقم النسخة السحابية.

Document ownership mismatch

لا يعني أن شخصًا آخر عدّل الملف. يعني أن نفس Document ID مرتبط بمعرّف حساب سحابي آخر. من الإصدار 2.3.2 يحفظ التطبيق نسخة أمان، ينشئ Document ID جديدًا للحساب الحالي، ثم يعيد المزامنة دون استبدال السجل السحابي الآخر.

النص العربي أو البوليت في الاتجاه الخطأ

تأكد أن أول حرف فعلي في البند عربي. الاتجاه يُحسب لكل بند على حدة؛ البنود التي تبدأ بالإنجليزية تبقى من اليسار.

Document Outline

Summary of figure outcomes

Each figure follows one of the five outcomes below.

Order 1 — KEEPKeep the figure as it is when copyright is clear and it already fits Teryaq style.
Order 2 — CHANGEMake specific minor changes when copyright is not an issue.
Order 3 — RECREATERecreate with AI using defined scientific-fidelity rules.
Order 4 — DESIGNCreate a new Teryaq-designed figure, especially charts and simple illustrations.
Order 5 — SEARCHSearch for a suitable figure when an appropriate one cannot be found by the draft writer.
Instructions & Notes

Order 1: only when the writer is certain there are no copyright issues and the style is suitable.

Order 3 defaults: Tajawal/English; change skin color and gender when suitable; minor color change; preserve anatomy/histology exactly; alter only non-scientific visual features; remove logos/signatures/watermarks/unnecessary titles; white background; final image 1:1. Any exception or extra change must be stated in PROMPT → DETAILS.

Order 4: clearly define the desired final output. Order 5: clearly describe what should be searched for.

Very important: figure code contains only the figure number; title is mandatory; caption is optional.

Steps of Creation
  1. Choose a clear, high-quality figure matching Teryaq usage.
  2. Add it to the Figure area.
  3. Write the figure code.
  4. Write a short title; use Caption for extra clarification.
  5. Always record the source.
  6. Choose the correct Order.
  7. Write details in PROMPT → DETAILS.
  8. Choose copyright status; use “I don't know” when uncertain.
  9. Add any extra notes.
