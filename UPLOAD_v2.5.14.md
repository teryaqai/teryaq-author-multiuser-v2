# TERYAQ Master Tool v2.5.14 — deployment and review

## Deploy

1. Replace the repository files with this release folder and deploy to Render.
2. Open the app online on every installed device once. Verify the Dashboard shows v2.5.14 before working offline.
3. No SQL migration or Edge Function change is needed.

## Review

1. In Shooting Script, open Script Cues and click **+ Heading**. Type an Arabic or English section title. Confirm the tinted box fills the script text area and can be edited or removed.
2. Press Enter after a heading. Confirm it adds an ordinary spoken line, and that Save/reopen preserves both lines.
3. Open Teleprompter. Confirm it only shows the spoken line; it does not display the heading as spoken text or pause at it.
4. Export PDF/HTML. Confirm the heading appears in a full-width highlighted box ahead of the spoken line. Open an existing script without headings and confirm it still works.
5. Check a Scientific Draft Text and Figures document for regressions.

The heading box uses an initial mint highlight. Align its exact visual style against the supplied example image when received.
